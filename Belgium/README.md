# Belgium — Fry-ndship

Fit edge_m against perimeter and ditch_m with an intercept, then plot the spatial residuals.

## Run

Use a separate Python environment. Run from this country directory.

```bash
python -m pip install -r requirements.txt
mkdir -p outputs
python main.py
```
