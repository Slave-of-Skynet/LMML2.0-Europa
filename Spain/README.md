# Spain — ¡Feliz Navidad!

Join purchase records against the office price guide and reconstruct the anomalous office grid.

## Run

Use a separate Python environment. Run from this country directory.

```bash
python -m pip install -r requirements.txt
mkdir -p outputs
python solve.py
```

## Input and output

office_price_guide.csv and purchases.csv.

Obtain task materials from the organizer task card; preserve their original filenames. Generated results belong in `outputs/` or another directory outside Git.

Organizer material: [source 1](https://drive.google.com/drive/folders/1w4N7Y662Ak5SYM2uF-K5vzJ28y41BlIQ).
