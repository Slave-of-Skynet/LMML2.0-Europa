# Estonia — This Data Is Perfect!

Identify preprocessing leakage and recompute evaluation with a split before scaling and fitting.

## Run

Use a separate Python environment. Run from this country directory.

```bash
python -m pip install -r requirements.txt
mkdir -p outputs
python solve.py
```

## Input and output

applications.csv.

Obtain task materials from the organizer task card; preserve their original filenames. Generated results belong in `outputs/` or another directory outside Git.

Organizer material: [source 1](https://drive.google.com/drive/folders/1fm_W5IUr4P4bnh2hyWDFbnYN-cZrhOkx).
