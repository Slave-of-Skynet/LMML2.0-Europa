# Moldova — Feather Stories

Learn site distortions and ring classes, then explain the observations and isolate the unregistered stork.

## Run

Use a separate Python environment. Run from this country directory.

```bash
python -m pip install -r requirements.txt
mkdir -p outputs
python main.py --data-dir /path/to/materials --output outputs/findings.json
```

## Input and output

observations.csv and ring_register.csv.

Obtain task materials from the organizer task card; preserve their original filenames. Generated results belong in `outputs/` or another directory outside Git.

Organizer material: [source 1](https://drive.google.com/drive/folders/1R_cYNcO-t0MRR2ri6Nhgj1cSJ7zCiWBM?usp=sharing).
