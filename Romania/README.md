# Romania — Shaken, Still Standing

Train the participant estimator and predict the sealed observations under the official output contract.

## Run

Use a separate Python environment. Run from this country directory.

```bash
python -m pip install -r requirements.txt
mkdir -p outputs
python main.py
```

## Input and output

The official training and sealed CSV files; see main.py for its CLI.

Obtain task materials from the organizer task card; preserve their original filenames. Generated results belong in `outputs/` or another directory outside Git.

Organizer material: [source 1](https://drive.google.com/drive/folders/1dCTKtIKpRqyJs57fN6nqIR2RuYuwt-Hd?usp=sharing).
