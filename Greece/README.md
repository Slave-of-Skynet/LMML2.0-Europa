# Greece — Just a siblings' thing

Compare the supplied sibling networks using their weights and predictions on the provided labelled data.

## Run

Use a separate Python environment. Run from this country directory.

```bash
python -m pip install -r requirements.txt
mkdir -p outputs
python solve.py
```

## Input and output

test_dataset.csv, test_labels.csv and model_apollo.pth, model_ares.pth, model_athena.pth.

Obtain task materials from the organizer task card; preserve their original filenames. Generated results belong in `outputs/` or another directory outside Git.

Organizer material: [source 1](https://drive.google.com/drive/folders/1wg1-xfTWUagA78WRMw3PU9PN4BU1mqns).
