# Finland — Pipes, Leaks, and the Graph Beneath

Compare the supplied route graph against the clean network to isolate the abnormal topology.

## Run

Use a separate Python environment. Run from this country directory.

```bash
python -m pip install -r requirements.txt
mkdir -p outputs
python solve.py
```

## Input and output

routes.csv and routes_clean.csv as required by the script.

Obtain task materials from the organizer task card; preserve their original filenames. Generated results belong in `outputs/` or another directory outside Git.

Organizer material: [source 1](https://drive.google.com/drive/folders/1vmtpg82kdxeFPGqs9IqUp80enMTYUTOR).
